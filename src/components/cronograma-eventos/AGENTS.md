# Agenda Fenasoja

- Choose official event locations by stable code in an explicit selector, while preserving free-text locations without a code — why: historical names remain intact and the restaurant alert only applies to the officially selected Center.
- The CCPF is one `commissions` row (slug `ccpf`) whose `commission_responsibles` feed both the Agenda selector and the Ecosystem root node; it is excluded from level-4 units and portal cards — why: one institutional source without a duplicate council or extra permissions.
- Portraits registered by user ID in `personPhotos.ts` take precedence over stored avatar URLs in every module — why: the Agenda and Ecosystem must show the same chosen official photo.
